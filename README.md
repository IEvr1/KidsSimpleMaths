# Kids Simple Maths

Εφαρμογή απλών μαθηματικών για παιδιά δημοτικού (Expo — mobile + web).

## Features

- Πρόσθεση και αφαίρεση έως 50
- Οι μαθητές γράφουν την απάντηση (όχι multiple choice)
- Πολλαπλασιασμός: πίνακες 1–10 + 11×11, 12×12, 13×13, 10×11
- Διαίρεση: ακέραιες με μικρά νούμερα
- Πόντοι: πρόσθεση/αφαίρεση 0.25, πολλαπλασιασμός/διαίρεση 1 (+ ίδιο μπόνους σειράς κάθε 5 σωστές)
- Στόχος πόντων από γονέα (PIN προεπιλογής: 1234)
- Ελληνικά / Αγγλικά (toggle ΕΛ | EN)

## Run

```bash
npm install
npm run web      # browser
npm run android  # Android (Expo Go)
npm run ios      # iOS (macOS + Expo Go)
```

## Parent zone

Κράτα πατημένο «Κράτα πατημένο 3 δευτ. για γονέα» στην αρχική, ή πήγαινε στο `/parent`. Προεπιλογή PIN: **1234**.
